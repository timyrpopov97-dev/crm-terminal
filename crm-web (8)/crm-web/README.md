# CRM Terminal — свой сайт с базой данных

Инструкция ниже проведёт вас от файлов на компьютере до рабочей ссылки
вида `https://ваш-проект.vercel.app`. Всё бесплатно. Читайте по порядку,
ничего не пропускайте.

---

## Шаг 0. Установите Node.js (один раз)

1. Откройте https://nodejs.org
2. Скачайте версию **LTS** под вашу систему (Windows/Mac).
3. Установите как обычную программу — просто «Далее → Далее → Готово».
4. Проверка: откройте терминал (на Mac — приложение «Терминал», на
   Windows — «PowerShell») и введите:
   ```
   node -v
   ```
   Если видите номер версии (например `v20.11.0`) — всё получилось.

---

## Шаг 1. Создайте базу данных на Supabase (бесплатно)

1. Зайдите на https://supabase.com → **Start your project** → войдите
   через GitHub или email.
2. Нажмите **New project**.
   - Задайте любое имя проекта, например `crm-terminal`.
   - Придумайте пароль базы данных (сохраните его куда-нибудь, но он
     дальше не понадобится — только для входа в саму базу напрямую).
   - Регион — любой ближайший.
3. Подождите 1–2 минуты, пока Supabase создаёт проект.
4. Слева в меню откройте **SQL Editor** → **New query**.
5. Откройте файл `schema.sql` из этого проекта, скопируйте всё
   содержимое, вставьте в редактор на Supabase и нажмите **Run**.
   Должно появиться "Success. No rows returned".
6. Слева в меню откройте **Settings → API**. Вам нужны два значения:
   - **Project URL** (выглядит как `https://xxxxx.supabase.co`)
   - **anon public** ключ (длинная строка)

   Сохраните их — понадобятся на следующем шаге.

7. **Важно про подтверждение почты.** По умолчанию Supabase требует
   подтвердить email при регистрации (шлёт письмо со ссылкой). Если
   хотите, чтобы вход работал сразу без писем — зайдите в
   **Authentication → Providers → Email** и выключите
   **Confirm email**.

---

## Шаг 2. Впишите ключи в проект

1. В папке проекта найдите файл `.env.local.example`.
2. Сделайте его копию и переименуйте копию в `.env.local`
   (точка в начале обязательна).
3. Откройте `.env.local` любым текстовым редактором и впишите
   значения из Supabase:
   ```
   NEXT_PUBLIC_SUPABASE_URL=https://xxxxx.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=длинный-ключ-из-supabase
   ```
4. Сохраните файл.

## Шаг 3. Запустите сайт локально (проверка)

В терминале перейдите в папку проекта и выполните:

```
cd путь/до/папки/crm-web
npm install
npm run dev
```

Откройте в браузере http://localhost:3000 — должна открыться страница
входа в хакерском стиле. Зарегистрируйтесь, войдите, добавьте сделку —
если всё работает, переходите к деплою. Если видите ошибку — пришлите
мне текст ошибки, поправим.

Остановить локальный сервер: `Ctrl + C` в терминале.

## Шаг 4. Выложите сайт в интернет через Vercel (бесплатно)

Самый простой способ — без GitHub, через командную строку.

1. В терминале, в папке проекта, выполните:
   ```
   npx vercel
   ```
2. Первый запуск попросит войти — откроется браузер, войдите через
   GitHub, Google или email (это бесплатный аккаунт Vercel).
3. Vercel задаст несколько вопросов — на всё можно отвечать Enter
   (значения по умолчанию подходят):
   - `Set up and deploy?` → Enter (Yes)
   - `Which scope?` → Enter (ваш аккаунт)
   - `Link to existing project?` → N
   - `What's your project's name?` → Enter (можно своё имя)
   - `In which directory is your code located?` → Enter (текущая)
   - Остальное — Enter
4. Через минуту вы получите ссылку вида
   `https://crm-terminal-xxxx.vercel.app` — это уже рабочий сайт,
   но пока без базы данных (переменные окружения ещё не добавлены).

5. Добавьте переменные окружения в Vercel:
   - Зайдите на https://vercel.com → откройте ваш проект
   - **Settings → Environment Variables**
   - Добавьте те же два значения, что и в `.env.local`:
     - `NEXT_PUBLIC_SUPABASE_URL`
     - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - Сохраните.

6. Пересоберите сайт с новыми переменными:
   ```
   npx vercel --prod
   ```

Готово — ссылка `https://ваш-проект.vercel.app` теперь полностью
рабочая, с настоящей базой данных, доступна с любого телефона и
браузера по HTTPS.

## Что умеет сайт

- Регистрация и вход по email/паролю (настоящий, через Supabase Auth)
- У каждого пользователя — свои сделки, чужих не видно (Row Level
  Security в базе данных)
- Канбан-доска: Лид → Переговоры → Закрыто → Отказ
- **Переименование колонок** — нажмите на карандаш ✏️ рядом с
  названием колонки, впишите своё, Enter. Название сохраняется
  персонально для вас и сразу отражается в кнопках быстрого переноса
- Перетаскивание карточек пальцем/мышью между колонками
- Кнопки мгновенного переноса в любую колонку (с актуальными
  названиями)
- **Конвертер валют по живому курсу**: ₴ / $ / € / ₿ (BTC) / Ξ (ETH) /
  ₮ (USDT) — суммы каждой сделки честно пересчитываются в выбранную
  валюту по актуальному курсу (не просто меняется значок). Курсы
  берутся с open.er-api.com (фиат) и CoinGecko (крипта), кешируются
  на 5 минут, кнопка обновления рядом с переключателем валют
- Описание сделки
- Звонок, WhatsApp, Telegram по номеру телефона; Gmail и копирование
  по email — здесь это уже **настоящий сайт в настоящем браузере**,
  так что переходы в приложения работают без ограничений песочницы.

## Автоматический сбор лидов из Telegram (новая версия)

Простая интеграция: бот в ваших торговых группах пересылает сообщения на сайт. На текущий момент вебхук просто **принимает сообщения** — вы можете использовать это как базу для дальнейшей автоматизации (добавить ИИ-анализ позже, если нужно).

### Шаг 1. Создайте Telegram-бота

1. В Telegram найдите **@BotFather**
2. Напишите `/newbot`
3. Придумайте имя (например, `Lead Collector`) и юзернейм (должен заканчиваться на `bot`, например `myleads_bot_2025`)
4. BotFather пришлет **токен** вида `123456789:ABCdef...` — **сохраните его**
5. Отправьте `@BotFather` → `/setprivacy` → выберите бота → **Disable** (важно — без этого бот видит только команды)

### Шаг 2. Добавьте бота в свои группы

1. Откройте группу в Telegram
2. Название группы → **Участники → Добавить** (или ➕)
3. Найдите бота по юзернейму → добавьте

**Повторите для каждой группы**, которую хотите отслеживать.

### Шаг 3. Добавьте переменные в Vercel

**Settings → Environment Variables** добавьте:

| Имя | Значение |
|---|---|
| `TELEGRAM_WEBHOOK_SECRET` | Придумайте любую случайную строку, например `my_secret_xyz_2025` |

### Шаг 4. Подключите вебхук

В браузере откройте **адресную строку** и вставьте (замените `<ТОКЕН>`, `<домен>`, `<СЕКРЕТ>`):

```
https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=https://<домен>.vercel.app/api/tg&secret_token=<СЕКРЕТ>
```

**Конкретный пример** (замените только токен и домен):
```
https://api.telegram.org/bot123456789:ABCdef.../setWebhook?url=https://crm-terminal-ten.vercel.app/api/tg&secret_token=my_secret_xyz_2025
```

Нажмите Enter. Браузер покажет: `{"ok":true,"result":true,...}` — значит, всё настроено.

### Проверка

Напишите что-то в группе, где бот добавлен. Вебхук будет получать сообщение. На данный момент это базовая функция — сообщения приёмываются, можно позже добавить автоматический анализ ИИ и создание лидов, если нужно.

Если нужны **вручную** отбирать лидов из открытых данных (компании по типу и городу) — это отдельная фича, расскажу дальше.

Бот, добавленный в торговые Telegram-группы («export hub» и т.п.),
пересылает каждое новое сообщение на ваш сайт. ИИ (Claude) читает
сообщение и решает: похоже ли упомянутое в нём на покупателя вашего
товара. Если да — карточка сама появляется в колонке «Лид» с
пояснением, почему ИИ так решил. Если нет — просто пропускается,
ничего не засоряет доску.

### Что нужно один раз настроить

**1. Создайте Telegram-бота**
1. В Telegram напишите **@BotFather** → `/newbot`
2. Придумайте имя и юзернейм (должен заканчиваться на `bot`)
3. BotFather пришлёт **токен** вида `123456:ABC-DEF...` — сохраните
4. Отправьте `@BotFather` команду `/setprivacy` → выберите вашего
   бота → **Disable**. Это важно: без этого бот в группах видит
   только сообщения, которые начинаются с `/` или явно к нему
   обращены, а не весь поток сообщений

**2. Добавьте бота в нужные группы**
- Откройте нужную торговую группу/чат в Telegram → Участники →
  Добавить → найдите вашего бота по юзернейму → добавьте

**3. Получите ключ Anthropic (оплата ИИ-анализа)**
1. Зайдите на https://console.anthropic.com → зарегистрируйтесь
2. Привяжите карту, пополните баланс (для начала хватит и пары
   долларов — один анализ стоит доли цента)
3. **API Keys** → **Create Key** → скопируйте ключ (начинается с
   `sk-ant-...`)

**4. Узнайте свой user_id в Supabase**
1. Supabase → **SQL Editor** → выполните:
   ```sql
   select id from auth.users where email = 'ваш-email@пример.com';
   ```
2. Скопируйте значение из колонки `id` — это длинная строка вида
   `a1b2c3d4-...`

**5. Возьмите Service Role ключ Supabase**
1. Supabase → **Settings → API**
2. Найдите **service_role** ключ (НЕ anon/public — именно service
   role, у него больше прав). Никому не показывайте этот ключ.

**6. Добавьте переменные окружения в Vercel**

Settings → Environment Variables, добавьте:

| Имя | Значение |
|---|---|
| `ANTHROPIC_API_KEY` | ключ из шага 3 |
| `SUPABASE_SERVICE_ROLE_KEY` | ключ из шага 5 |
| `LEADS_OWNER_USER_ID` | ваш user_id из шага 4 |
| `TELEGRAM_WEBHOOK_SECRET` | придумайте любую длинную случайную строку — например `myown-secret-8271hd` |

Сохраните → **Redeploy**, чтобы переменные подхватились.

**7. Подключите бота к сайту (webhook)**

На компьютере, в терминале (или через любой сервис вроде
reqbin.com, если не хочется ставить терминал), выполните один запрос
— замените `<ТОКЕН>`, `<ваш-сайт>` и `<ваш-секрет>` на свои значения:

```
curl "https://api.telegram.org/bot<ТОКЕН>/setWebhook?url=https://<ваш-сайт>.vercel.app/api/telegram-webhook&secret_token=<ваш-секрет>"
```

В ответ должно прийти `{"ok":true,"result":true,...}`.

### Как проверить, что работает

Напишите в группе, куда добавлен бот, тестовое сообщение, например:
> Ищем поставщика подсолнечного масла оптом, объём от 20 тонн в
> месяц, компания ТОВ «Агропродукт»

Через несколько секунд загляните на доску — в колонке «Лид» должна
появиться карточка «ТОВ Агропродукт» с пояснением от ИИ в описании.
Сообщение не по теме (например, про продажу мороженого) появляться
не должно — так и задумано, ИИ его отсеет.

### Важные оговорки

- Критерий, по которому ИИ отбирает лидов («покупатель подсолнечного
  масла...»), захардкожен в файле `app/api/telegram-webhook/route.js`
  в константе `CRITERIA` — отредактируйте текст под себя, если нужно
  сузить/расширить критерий, и задеплойте заново.
- Бот видит только те группы, куда его добавили вручную — это не
  массовый парсинг чужих чатов, а чтение сообщений в группах, куда у
  вас и так есть доступ.
- Каждое сообщение = один короткий запрос к Claude, это недорого, но
  не бесплатно — если группа очень активная (сотни сообщений в день),
  проверьте расход на console.anthropic.com.
- В текущей версии нет проверки на дубликаты — если одна и та же
  компания упомянута дважды, может создаться две карточки. Можно
  доработать при необходимости.


Если база уже была создана раньше (до появления переименования
колонок), выполните в Supabase → SQL Editor только новый кусок — он
не тронет уже существующие сделки:

```sql
create table if not exists board_settings (
  user_id uuid references auth.users primary key,
  column_labels jsonb default '{}'::jsonb,
  currency text default 'UAH',
  updated_at timestamptz default now()
);

alter table board_settings enable row level security;

create policy "select own settings" on board_settings for select using (auth.uid() = user_id);
create policy "insert own settings" on board_settings for insert with check (auth.uid() = user_id);
create policy "update own settings" on board_settings for update using (auth.uid() = user_id);
```
