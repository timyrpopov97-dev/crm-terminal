# CRM Terminal — свой сайт с базой данных

Инструкция ниже проведёт вас от файлов на компьютере до рабочей ссылки
вида `https://ваш-проект.vercel.app`. Всё бесплатно. Читайте по порядку,
ничего не пропускайте.

---

## Шаг 0. Установите Node.js (один раз)

1. Откройте https://nodejs.org
2. Скачайте версию **LTS** под вашу систему (Windows/Mac).
3. Установите как обычную программу — просто «Далее → Далее → Готово».
4. Проверка: откройте терминал (на Mac — приложение «Терминал», на
   Windows — «PowerShell») и введите:
   ```
   node -v
   ```
   Если видите номер версии (например `v20.11.0`) — всё получилось.

---

## Шаг 1. Создайте базу данных на Supabase (бесплатно)

1. Зайдите на https://supabase.com → **Start your project** → войдите
   через GitHub или email.
2. Нажмите **New project**.
   - Задайте любое имя проекта, например `crm-terminal`.
   - Придумайте пароль базы данных (сохраните его куда-нибудь, но он
     дальше не понадобится — только для входа в саму базу напрямую).
   - Регион — любой ближайший.
3. Подождите 1–2 минуты, пока Supabase создаёт проект.
4. Слева в меню откройте **SQL Editor** → **New query**.
5. Откройте файл `schema.sql` из этого проекта, скопируйте всё
   содержимое, вставьте в редактор на Supabase и нажмите **Run**.
   Должно появиться "Success. No rows returned".
6. Слева в меню откройте **Settings → API**. Вам нужны два значения:
   - **Project URL** (выглядит как `https://xxxxx.supabase.co`)
   - **anon public** ключ (длинная строка)

   Сохраните их — понадобятся на следующем шаге.

7. **Важно про подтверждение почты.** По умолчанию Supabase требует
   подтвердить email при регистрации (шлёт письмо со ссылкой). Если
   хотите, чтобы вход работал сразу без писем — зайдите в
   **Authentication → Providers → Email** и выключите
   **Confirm email**.

---

## Шаг 2. Впишите ключи в проект

1. В папке проекта найдите файл `.env.local.example`.
2. Сделайте его копию и переименуйте копию в `.env.local`
   (точка в начале обязательна).
3. Откройте `.env.local` любым текстовым редактором и впишите
   значения из Supabase:
   ```
   NEXT_PUBLIC_SUPABASE_URL=https://xxxxx.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=длинный-ключ-из-supabase
   ```
4. Сохраните файл.

---

## Шаг 3. Запустите сайт локально (проверка)

В терминале перейдите в папку проекта и выполните:

```
cd путь/до/папки/crm-web
npm install
npm run dev
```

Откройте в браузере http://localhost:3000 — должна открыться страница
входа в хакерском стиле. Зарегистрируйтесь, войдите, добавьте сделку —
если всё работает, переходите к деплою. Если видите ошибку — пришлите
мне текст ошибки, поправим.

Остановить локальный сервер: `Ctrl + C` в терминале.

## Шаг 4. Выложите сайт в интернет через Vercel (бесплатно)

Самый простой способ — без GitHub, через командную строку.

1. В терминале, в папке проекта, выполните:
   ```
   npx vercel
   ```
2. Первый запуск попросит войти — откроется браузер, войдите через
   GitHub, Google или email (это бесплатный аккаунт Vercel).
3. Vercel задаст несколько вопросов — на всё можно отвечать Enter
   (значения по умолчанию подходят):
   - `Set up and deploy?` → Enter (Yes)
   - `Which scope?` → Enter (ваш аккаунт)
   - `Link to existing project?` → N
   - `What's your project's name?` → Enter (можно своё имя)
   - `In which directory is your code located?` → Enter (текущая)
   - Остальное — Enter
4. Через минуту вы получите ссылку вида
   `https://crm-terminal-xxxx.vercel.app` — это уже рабочий сайт,
   но пока без базы данных (переменные окружения ещё не добавлены).

5. Добавьте переменные окружения в Vercel:
   - Зайдите на https://vercel.com → откройте ваш проект
   - **Settings → Environment Variables**
   - Добавьте те же два значения, что и в `.env.local`:
     - `NEXT_PUBLIC_SUPABASE_URL`
     - `NEXT_PUBLIC_SUPABASE_ANON_KEY`
   - Сохраните.

6. Пересоберите сайт с новыми переменными:
   ```
   npx vercel --prod
   ```

Готово — ссылка `https://ваш-проект.vercel.app` теперь полностью
рабочая, с настоящей базой данных, доступна с любого телефона и
браузера по HTTPS.

## Если что-то не работает

Пришлите мне текст ошибки (или скриншот) — укажите, на каком шаге
она возникла. Я поправлю нужный файл, а вы обновите сайт:

```

```

Ссылка при этом не меняется — обновляется контент по той же ссылке.

## Как выглядит финальная структура проекта

```
crm-web/
├── app/
│   ├── layout.js         — общий каркас страниц
│   ├── page.js           — стартовая страница (редирект)
│   ├── globals.css       — стили в хакерском стиле
│   ├── login/page.js     — вход / регистрация
│   └── board/page.js     — сама CRM-доска
├── lib/
│   └── supabaseClient.js — подключение к базе данных
├── schema.sql             — SQL-схема таблицы сделок
├── .env.local.example     — образец переменных окружения
├── package.json
└── README.md               — этот файл
```

## Что умеет сайт

- Регистрация и вход по email/паролю (настоящий, через Supabase Auth)
- У каждого пользователя — свои сделки, чужих не видно (Row Level
  Security в базе данных)
- Канбан-доска: Лид → Переговоры → Закрыто → Отказ
- Перетаскивание карточек пальцем/мышью между колонками
- Кнопки мгновенного переноса в любую колонку
- Валюта ₴ / $ / €
- Описание сделки
- Звонок, WhatsApp, Telegram по номеру телефона; Gmail и копирование
  по email — и, в отличие от версии внутри Claude, здесь это уже
  **настоящий сайт в настоящем браузере**, так что переходы в
  приложения будут работать нормально, без ограничений песочницы.
